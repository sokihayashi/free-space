# STATION MAP

**文字を「地図そのもの」に変換するカバー画像ジェネレータ（p5.js）**
→ https://sokihayashi.github.io/free-space/station/

画像・SVG・テキストを入力すると、その字形を地図の構造として組み込んだ
1400〜3000px の正方形（ポッドキャストカバー規格）を生成します。

---

## 考え方

文字にテクスチャを流し込む（＝地図柄のステンシル）と、どうしても
「地図の上に文字が乗っている」絵になります。そうならないように、
**文字を地図の“地物”として発生させる**方式をとっています。

| モード | 文字は何になるか | 参照している地図表現 |
|---|---|---|
| **街区 (district)** | 都心の高密度地区 | 街区塗り分けのシティマップ・ポスター |
| **路線 (transit)** | 路線網そのもの | 東京メトロ / 大阪市営 などの路線図 |
| **陸と水 (coast)** | 陸地（外側が湾） | 東京湾を抜いたモノトーンの街路図 |

いずれのモードでも、街路網は文字の内外で **連続** します。
文字の領域だけ切り抜いて別の絵を貼る、ということはしていません。

### 街区の発生（city engine）

```
ボロノイで区に分割
  ↓  各区を「長い方の軸に直交」して再帰的に二分割
街区(block) と 切断線(cut) が同時に得られる
  ↓  切断の深さ = 道路の階層（幹線 5.4px 〜 路地 0.85px）
  ↓  密度場 = 都心からの距離 × 文字のSDF
文字の内側ほど街区が細かくなる ＝ 文字が「密度」として地図に入る
```

- **文字の輪郭は道路として描かれます**（マスクの縁ではなく、地図の要素）
- 湾は街区を欠いた形で刻まれるので、岸線が埠頭状になります

### 路線の発生（transit）

```
2値マスク → Zhang-Suen 細線化 → 骨格グラフ追跡
  ↓  Ramer–Douglas–Peucker で簡略化
  ↓  各区間に 45° の肘を挿入（八方位化・強さは可変）
  ↓  1本を 2〜3 本の並走線に展開（実際の路線図の密度感）
分岐 = 白いカプセル（乗換駅） / 終端 = 丸（終着駅）
  ↓  終端から連絡線が生えて、場外や他の文字へつながる
```

連絡線と文字の路線は **同じ描画規則** で描かれます。図と地に様式的な差がないので、
文字は「網の密な部分」として読まれます。

## 使い方

1. 画像 / SVG をドラッグ&ドロップ（⌘V の貼り付け、テキスト入力も可）
2. モードとパレットを選ぶ
3. `SEED 🎲` で構成を引き直す
4. `PNG 1400` / `PNG 3000` で書き出し

- 透過 PNG・SVG はアルファをそのまま使います。不透明画像は 2値化しきい値で調整
- 右下のサムネイル（112px）が、実際のポッドキャストアプリでの見え方
- 「陸/海コントラスト比」が 7:1 以上なら、サムネイルでも確実に読めます

### 入力素材のコツ

- **太い字形ほど良い結果になります**（細い線は街区も路線も入る余地がない）
- 路線モードは、字画が細切れになる書体（細い和文など）では骨格が分断されます。
  和文なら太ゴシック、または字形を単純化したロゴデータを推奨
- `文字サイズ` を 1.2〜1.5 にして版面から切れさせると、地図らしさが増します

## 技術

p5.js（`vendor/` に同梱・CDN 不要）+ Canvas 2D。ビルド不要・依存ゼロ。
描画は全て正規化座標で持っているため、1400px と 3000px で同一の構図が出ます。
