# STATION MAP

**文字を「都市計画の条件」にして地図を生成する**（p5.js / Canvas 2D）
→ https://sokihayashi.github.io/free-space/station/

画像・SVG のロゴタイプをアップロードすると、その字形を**地図の構造そのもの**として
組み込んだ 1400〜3000px の正方形を生成します。

---

## 何をしていないか

文字は **マスクではありません**。
「街の絵を作ってから文字の形で切り抜く／色を替える」ことは一切していません。
それをやると、どれだけ手を入れても「背景の上に文字が乗った絵」にしかならないからです。

## 何をしているか

```
アップロード画像 / SVG
  → ① 領域フィールド（内外・縁からの距離・局所方位・街区の目標サイズ）
  → ② 道路網の成長（フィールドだけを見て 1 つの平面グラフを作る）
  → ③ 街区 ＝ 道路網の「面」を抽出
  → ④ 土地利用（市街地 / 水域 / 緑地）
  → ⑤ 街区を、接する道路の幅だけ内側にオフセットして塗る
  → ⑥ 112px に縮小して明度差を実測
```

### ① 文字は「街区の大きさ」と「街路の方位」を決める条件になる

字形の符号付き距離場から `grain`（その地点に作るべき街区の大きさ）を作ります。
文字の内側は細かく、外側は粗く。方位も、文字の内側は連結成分ごと（＝1 文字ごと）に
一貫した角度、外側は区ごとの角度。**道路網はこの場しか見ずに成長します。**

さらに、**字形の輪郭を直線の連なりに簡略化して、成長前のグラフに道路として植えます**。
以降の街路はこれにスナップ・分割されるので、街区が境界をまたぐことはありません。
文字の縁はフォントの輪郭ではなく、**実在する道路の線**になります。

### ② 道路網の成長（Parish & Müller 型）

区間を提案 →
- 既存ノードが近ければ **スナップして接続**（袋小路を作らない）
- 既存道路と交差すれば **交点で分割して交差点を作る**
- 近すぎる／短すぎる提案は **棄却**（これが密度の上限になる）

幹線 → 補助幹線 → 生活道路の 3 階層。方位場に沿った回転格子で種を撒くので、
文字の内側は「計画的な細かい碁盤」、外側は「粗い街区」として育ちます。

### ③ 街区 ＝ 面

平面グラフの面を辿って多角形にします。**街区の形は道路が決めています。**
（多角形を分割してから道路を描き足すのとは、ここが決定的に違います）

### ⑤ トーンは構造から生まれる（Nolli 図法）

街区を、接する道路の幅の分だけ内側にオフセットして塗ります。
道路は線として描かれず、街区と街区の**すき間**として現れます。したがって：

- 細かい街区 → すき間が多い → **明るい面**
- 大きい街区 → すき間が少ない → **暗い面**

文字が小さいサイズで読めるのは、この面としての明度差です。**色は使っていません。**
グレースケールにしても読めます。

## 文字の見せ方（可読性のチャンネル）

| | 文字の領域 | 効き |
|---|---|---|
| **粒度**（既定） | 細かい街区の地区になる | 強い。地図として最も自然 |
| **水域** | 水（湾）になる | 最強。岸線は街区の縁そのもの |
| **緑地** | 公園の塊になる | 中 |

補助として「文字の内側の建蔽率」も下げられます（低層・小街区の地区）。

---

## 可読性の実測

出力を **112px**（ポッドキャストアプリでの実表示サイズ）に縮小し、
文字の領域とそれ以外の平均輝度差 **ΔL** を測って表示します。

- `ΔL ≥ 0.18` … 読める
- 足りないときは **粒度比** と **建蔽率**、または **文字サイズ** を上げる

装飾ではなく、生成パラメータを調整するための計器です。

---

## 使い方

1. 画像 / SVG をドラッグ&ドロップ（⌘V も可）
2. 「文字の見せ方」を選ぶ
3. `SEED 🎲` で都市を引き直す
4. `PNG 1400` / `PNG 3000` で書き出し

### 素材のコツ

- **太い字形ほど良い結果になります**。字画の幅に対して街区は 1/3〜1/4 の大きさになるので、
  字画が細いと街区 1〜2 個ぶんしか入らず、字形が解像できません
- 透過 PNG・SVG はアルファをそのまま字形として使います
- `文字サイズ` を 1.1〜1.3 にして版面から少し切れさせると地図らしくなります

## 構成

```
station/
  index.html
  sketch.js            エントリ（状態・p5・書き出し）
  src/field.js         領域フィールド（SDF・連結成分・境界の簡略化）
  src/network.js       道路網の成長
  src/blocks.js        面の抽出と土地利用
  src/render.js        描画（Nolli 図法）
  src/legibility.js    112px での明度差の実測
  src/ui.js            素材読み込み・パラメータ・書き出し
  vendor/p5.min.js
```

依存ゼロ・ビルド不要。すべて正規化座標なので 1400px と 3000px で構図が一致します。
